# 张雅书创意作品集

一套可编辑的中文个人作品集网站，使用 React、TypeScript、Vite、Tailwind CSS、Framer Motion 与 Lucide React 构建。

## 本地运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
npm run preview
```

构建结果位于 `dist/`，可直接部署到 GitHub Pages、Cloudflare Pages、Netlify 或其他静态托管服务。Vite 的 `base` 已设置为 `./`，也可以直接打开静态服务器中的子目录。

GitHub Pages 的自动部署步骤见 `GITHUB_PAGES_DEPLOY.md`。轻量部署包已内置 GitHub Actions 工作流。

## 内容维护

- 所有作品数据集中在 `src/data/portfolio.ts`。
- 图片与视频位于 `public/assets/`，网页引用使用 ASCII 文件名。
- 新增作品时，先把素材放入对应目录，再在数据文件中新增条目。
- 活动与网页链接仅使用旧作品集中已存在的真实 URL。
- 联系方式在 `src/data/portfolio.ts` 的 `contact` 对象中填写。

## 素材说明

当前已接入：头像 1 张、活动横幅 8 张、完整启动页 4 张、互动网页截图 3 张、动态视频 7 条及对应封面 7 张。

待补充素材统一记录在 `MISSING_ASSETS.md`，页面不会用虚假图片、邮箱或链接替代。

## 交互说明

- 首页人物使用单张透明 PNG，仅实现小幅头部跟随与呼吸浮动，不进行脸部网格变形。
- 首页大标题为“你好，张雅书”，人物保持在标题下方；左下角恢复“海外社交 APP 运营 / 活动策划 · AI 视觉创作”。
- 首页“张雅书”三字使用同一基线与间距，人物位于文字前方形成前后叠层。
- 作品目录使用 01–04 四行简洁索引；活动企划、启动视觉、互动网页、动态创作均使用 React Bits ScrollStack，项目卡片在页面滚动时缩放、变暗并逐张覆盖。
- 三个互动网页直接加载真实项目地址。默认状态可观看自动加载的实时页面，点击“进入实时预览”后可在卡片内独立滚动和操作；右上角可退出预览。
- 页面支持 `prefers-reduced-motion`，触屏设备关闭光标跟随。
- “查看全部作品”、图片灯箱、网页外链、视频播放/暂停和放大播放均为真实可用交互。
- 视频由访客点击播放，播放新作品时会暂停其他视频，离开可视区域后也会暂停，避免多条视频同时占用资源。

> 实时网页预览需要联网。若目标站点暂时无法访问，卡片会保留本地真实项目截图作为加载占位，外链按钮仍可直接打开原项目。
